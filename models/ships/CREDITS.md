# Ship model credits

| File | Ship | Author | License | Source |
|---|---|---|---|---|
| `carrier.glb` | Nimitz-class aircraft carrier (generic, hull number 73) | SKYWAR — built in Blender by `tools/ships/carrier_model.py`; deck and hull textures generated by `tools/ships/ship_textures.py` | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) | this repository (`sh tools/ships/build.sh`) |
| `destroyer.glb` | Arleigh Burke-class (Flight IIA) destroyer (generic, hull number 51) | SKYWAR — built in Blender by `tools/ships/destroyer_model.py` (same texture script) | CC0 1.0 | this repository |

Both models are original work: geometry and textures are produced entirely by the scripts above (no
third-party meshes, photos or textures). Proportions follow published dimensions of the real classes
(Nimitz: LOA ~333 m, flight deck ~77 m wide, waterline beam ~41 m, draught ~11 m; DDG-51 Flight IIA:
LOA 155 m, beam 20 m) scaled to the game's existing gameplay constants in `src/naval.js`. Numerals are
rendered with a system font (Arial Black) at build time.

A ready-made DDG-51 GLB exists in https://github.com/Void0312Aurora/Echelon-Forge
(`examples/viz/web_viz/static/assets/naval/ddg51.glb`), but unlike that repo's aircraft and missile assets
it has no attribution/licence record of its own (the repository's Apache-2.0 licence does not establish
the model's origin), so it was not used.
